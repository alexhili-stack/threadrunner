# Local release checklist

- Run the full QA wrapper and 15-minute soak; preserve logs and counts.
- Export the Windows x64 release from the exact pinned engine/template.
- Launch the release and separately verify gameplay, save/relaunch and quitting.
- Exclude development tools, tests and fixtures from the exported package.
- Keep engine/third-party licences and credits available with the build.
- Record build ID, target, executable/PCK checksums and associated acceptance report.
- Inspect rendered menus, settings, room, pause and clear screen at supported sizes.
- Human playtest feel, difficulty, readability, bindings, sound and a physical controller.
- Verify current Steamworks requirements, working-title availability and store claims before any public release.

Local materials only. No accounts, uploads, submission, payments or publication are authorised. macOS/Linux/Steam Deck, achievements, cloud saves and leaderboards are not advertised support.
